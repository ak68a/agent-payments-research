# ack-research

RFC drafts and proposals for the [Agent Commerce Kit](https://github.com/agentcommercekit/ack) ecosystem.

Each directory is a self-contained proposal with its own README, spec document, diagrams, and working examples. Proposals live here as working drafts until they're ready to submit as PRs to the upstream ACK repo.

## Process

1. Draft the proposal here with spec, diagrams, and a working `jose` example
2. Run a self-review against the [Matt-style review checklist](CLAUDE.md)
3. Open an issue on `agentcommercekit/ack` with the motivation and concept diagram
4. If the maintainer is receptive, open a PR adding the spec to `docs/` in the ACK repo
